# Radio test bundles

Upload `aether-test-*.tar.gz` files here: in the app, Diagnostics → Radio test → Finish test → "Upload for the developer", then drag the file onto the page and click **Commit changes**.

This branch holds test evidence only; it is never merged into `main`. A bundle contains the test's captures (what went over the air, including chat text and file contents), the engine log, the configuration without passwords, and a summary.
