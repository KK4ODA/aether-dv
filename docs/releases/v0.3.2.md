**Fix: larger files on DV slow data.** In the bench test a 20 kB file got stuck at 0 blocks. Aether DV wrote about 1,260 bytes to the IC-9700 at once, but the radio keeps only about one transmission's worth and drops the rest. Every block arrived cut short.

- **Radio-sized pieces.** On DV slow data, Aether DV writes at most 180 bytes of whole frames at a time, lets each piece go on the air, then writes the next. It checks the radio's "wait" signal before every write.
- **Smaller file blocks:** 120 bytes, so each block fits in one transmission. D-RATS stations accept any block size.
- **Expect about 25–30 bytes per second** for files on DV slow data with these radios, because each block takes its own transmission. A 5 kB file takes a few minutes. DV Fast Data is the faster option, still to be tested.
- **Header:** a call sign with an SSID (KK4ODA-1) gets its own line under the name, instead of wrapping.

Still **tested on the bench only**: two radios on simplex, no repeaters or D-RATS stations yet.
