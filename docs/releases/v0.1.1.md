**Renamed programs.** The names no longer clash with Aether HF, so both can be installed on the same computer:

| Before (0.1.0) | Now |
|---|---|
| `aetherd` (engine) | `aetherdv` |
| `aether-cli` | `aetherdv-cli` |
| `aether-bench` | `aetherdv-bench` |
| `aether-rfd` (ratflector server) | `aetherdv-rfd` |
| `aecap` (capture reader) | `aetherdv-cap` |
| `aetherd.token` | `aetherdv.token` |
| `AETHER_TOKEN_FILE`, `AETHER_API` | `AETHERDV_TOKEN_FILE`, `AETHERDV_API` |

Unchanged:
- **Configuration files:** no edits needed.
- **Capture files:** `.aecap` still reads as before.
- **API address:** still `127.0.0.1:7373` by default.

If you start the engine yourself, use `aetherdv --config …` and point the app at `aetherdv.token`. The app starts the bundled engine under its new name automatically.

Still **tested in simulation only**: no tests with real D-RATS stations, real radios or over the air yet.
