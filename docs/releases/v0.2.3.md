**From the first bench tests.** Changes found while testing an IC-9700 and an ID-52 PLUS on simplex.

- **Chat: type any call sign in To.** To used to list only stations already heard, so you couldn't address a station before it had transmitted. Now you can type any call sign; heard stations are suggested, and an empty field sends to everyone (CQCQCQ).
- **Chat: your own call sign in red italics** on the lines you sent, so they stand out from received lines.
- **Radio test summary shows more:**
  - a **Received** section: when data arrived and how much;
  - **channel changes** in the timeline: when the radio reported voice, a signal or a clear channel over CI-V;
  - plainer port lines, for example `radio UR "CQCQCQ" R1 "W4DOC  D" R2 "W4DOC  G" (read over CI-V)` and "no air-time limit on this path".

First on-air results: the ID-52 PLUS holds data while it's receiving a D-STAR voice call and sends it when the channel clears. The IC-9700 reports the call signs it's set to, and who it's receiving, over CI-V.
