**Faster, cleaner file transfers on DV slow data.** In the 0.3.2 bench test a 5 kB file arrived, but slowly (about 12 bytes per second). Writing 4 blocks to the IC-9700 takes 12–20 seconds, one transmission per block. The retry timer kept running meanwhile and expired before the last block was on the air. The radio then asked for an acknowledgement while the other station was answering, and the two transmissions collided.

- **Transfer timers wait while a burst is being written.** They start counting only once the radio has taken all of it. This removes the collisions and the resends they caused.
- **Radio test summary:** a new **overs** column shows how many transmissions each burst took. Key-up and air time are left blank for bursts sent in several transmissions, where they can't be measured.

Still **tested on the bench only**: two radios on simplex, no repeaters or D-RATS stations yet.
