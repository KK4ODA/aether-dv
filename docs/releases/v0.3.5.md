**Transmission size setting, and a quieter IC-9700 while sending.**

- **Transmission size**, in each DV slow data port's window (click the port in the top bar):
  - **180 bytes (tested)** is the default.
  - **220 bytes** puts the acknowledgement and the request for one together with a data block. That's 8 transmissions per group of 8 blocks instead of 10, so files go faster. The radios haven't been proven to take 220 bytes whole. If they drop bytes, the blocks are resent: you'll see retries, but files are never damaged.

  The choice applies immediately and is remembered on this computer. `piece_bytes` in the configuration sets the starting value.
- **CI-V stays quiet for the whole of each transmission.** Aether DV already paused its CI-V queries while handing data to the radio, but only for 10 seconds. A group of 8 blocks takes 30–45 s on the IC-9700, so the queries restarted partway through and slowed the radio down. The pause now lasts until the radio has taken everything.

Still **tested on the bench only**: two radios on simplex, no repeaters or D-RATS stations yet.
