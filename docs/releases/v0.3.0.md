**Chat and files, as in D-RATS.**

- **To** is a list: **Everyone (CQCQCQ)** first, then heard stations, then **Other call sign…** to type one.
- **A tab per station.** Click a station under **Heard**, or receive a message addressed to you, and that station gets its own tab. It shows only the traffic between you and that station, sends only to it, and counts unread messages. × closes it.
- **Clear** (or **Ctrl+L**) empties the current tab. Messages stay in the history and in test recordings; **Show all** brings them back.
- **Right-click Heard** for **Ping all stations**. Right-click a station for **Open conversation**, **Ping**, **Get version** or **Send file…**. Ping replies show the round-trip time.
- **Send files from the app:** **Send file…** next to **Send**, or drop a file on the chat. You see the size, station, port and time on air before it goes. When it's done, the station's tab says so.
- **Received files** go to `Documents\Aether DV\Received\YOUR-CALL`, unless your configuration sets `files_dir`. The chat line has **Show file**, and **Transfers** has **Open received files**.
- **Cancel** a message that's still queued, or a transfer under **Waiting to send**.
- **Ctrl+1–9** switch tabs.

The command line still works for everything (`aetherdv-cli send-file …`).

Still **tested on the bench only**: two radios on simplex, no repeaters or D-RATS stations yet.
