**Fix: Start the engine missing on the connect screen.** In 0.2.1, the connect screen could show only **Token file** and **Engine address**, without **Configuration file** and **Start the engine**. It happened when the app's start-up check for its bundled engine finished after the first connection attempt. The screen now waits for that check, so the button always appears on installs that include the engine.

Also on the connect screen:
- On first start it says "No engine is running yet. Enter your configuration file and click Start the engine." instead of listing where it looked for a token.
- A configuration file entered as **Token file** gets an explanation that it belongs in **Configuration file**.
- Quotation marks around a pasted path (Windows **Copy as path**) are removed.

The IC-9700 setup steps in **Radio Setup** now give the full menu paths from Icom's manual: `SET > Connectors > USB (B)/DATA Function` and `MENU > GPS > GPS TX Mode`.

Still **tested in simulation only**: no real radios, repeaters or D-RATS stations yet.
