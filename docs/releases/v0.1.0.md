First preview of Aether DV, a D-RATS-compatible D-STAR data application.

**Tested in simulation only.** No interoperability tests with real D-RATS stations, and no tests on real radios or over the air, have been done yet. Use it alongside D-RATS, not instead of it.

What's in it:
- **Engine (`aetherd`)**
  - Ports: serial radio ports and ratflector connections.
  - Legacy D-RATS behaviour: chat, ping, version query, file and form transfer.
  - ICS-213 messages, and position reports (NMEA and DPRS).
  - Diagnostics: wire capture (`.aecap`) and support bundles.
- **Desktop app**
  - Views: Chat, Messages (ICS-213), Transfers, Stations and Diagnostics.
  - Radio Setup: step-by-step setup per brand and model, with links. Guides start from manuals only and are updated from operators' reports.
  - Sounds: an optional sound for each kind of event, each switchable.
  - Engine: it can start the bundled engine with your configuration file.
  - Updates: "Check for updates" is in Diagnostics; updates install only when you click Install.
- **Command line:** `aether-cli`, and `aether-bench` for scripted interop runs.
- **CI-V:** checks that the radio's DV Fast Data setting matches the port (IC-9700, ID-52 PLUS).

Known limits:
- Installers are not code-signed for Windows or notarised for macOS. Expect a security warning on first install.
- macOS builds are for Apple silicon only.
- No map, settings screen or file picker yet. Ports are set up in the configuration file (see `examples/` in the source).
