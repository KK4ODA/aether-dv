**Fix: the update card shows its Install button.** Up to 0.2.3, the card that offers a new version showed text like `[object HTMLParagraphElement]` instead of **Install and restart** and **Later**. The port route window and the Diagnostics header had the same fault and are fixed too.

**Install this version by hand.** The fix only works once it's installed, so your current version can't show the button for this update:
1. Close Aether DV. If you started an engine yourself, stop it too.
2. From this release, download the installer of the same type you used before: `…_x64-setup.exe` or `…_x64_en-US.msi` on Windows, `.dmg` on macOS, or your usual Linux package.
3. Run it. Settings, configuration files and recordings are kept.

From 0.2.4 on, updates install from the button again.

Also:
- **Radio test summary:** "Messages waited, by reason" now counts only time when a message was actually waiting. It used to add up every busy period, even with nothing to send.
- **Credits:** Diagnostics has a new **About** section, crediting D-RATS and the people who built and maintain it. Aether DV speaks the D-RATS protocol.

Still **tested on the bench only**: two radios on simplex, no repeaters or D-RATS stations yet.
