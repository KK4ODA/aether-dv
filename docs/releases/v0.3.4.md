**Faster files on DV slow data, and a safety note for simplex.**

- **About 25% faster file transfers.** After each group of blocks, the acknowledgement from the other station was wrongly ignored as "too early", and Aether DV waited for its retry timer, about 12 seconds every time. That's fixed. Groups are now 8 blocks instead of 4, so there are half as many round trips. Over a simulated link a 3 kB file now takes about 81 seconds, against about 110 before.
- **R2 gateway note.** On a simplex port, if the radio still has a repeater gateway in R2 (for example `W4DOC  G`), Aether DV says so in the port's window and next to the chat box. It's harmless on simplex, but on that repeater your data would go out to its linked reflector. Nothing is blocked.
- **IC-9700 setup:** set CI-V Transceive to OFF. Aether DV asks the radio for what it needs.
- **For experiments:** `piece_bytes` in a serial port's configuration (default 180) sets the most bytes written per transmission on DV slow data.

Still **tested on the bench only**: two radios on simplex, no repeaters or D-RATS stations yet.
