**From bench Tests 5b and 5c (IC-9700 and ID-52 PLUS).** Full results: `docs/bench-results.md`.

- **The IC-9700 sends each block in one transmission again.** 0.2.5 started writing data to the radio in small pieces. The IC-9700 transmits what it has and takes nothing more until it's finished, so one block went out as several short transmissions. Each block is now written in one go; the radio's "wait" signal holds back the next block.
- **No more duplicate file offers.** The IC-9700 sometimes takes several seconds to accept data. Retry timers now start when the radio actually takes the data, not when Aether DV hands it over.
- **Faster IC-9700 key-up.** Aether DV's CI-V queries roughly tripled how long the IC-9700 took to accept data (Test 5c). Aether DV now stops querying while a block goes to the radio.
- **Transfers say where they are:** *Waiting for KK4ODA-1 to accept*, *3 of 12 blocks acknowledged*. A small file is a single block, so its bar jumps from 0 to 100%.
- **Radio test summary:** key-up is measured even when the radio is slow; the radio's XOFF/XON bytes are no longer counted as received data; write waits appear in the timeline.

Still **tested on the bench only**: two radios on simplex, no repeaters or D-RATS stations yet.
