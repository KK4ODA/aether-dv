# ADR-0008: Licence GPL-3.0-or-later; protocol spec CC-BY-4.0

Status: **Accepted** 2026-10-29 (owner decision) · Proposed: 2026-10-29

See `../09-licensing.md`. The implementers have read GPL D-RATS source, so a clean-room claim is not defensible. GPL-3.0-or-later avoids the question and allows bundling legacy forms. Never copy MMDVMHost GPL-2.0-only files. Never ship third-party API keys.

## Decision record (2026-10-29)
Owner accepted **GPL-3.0-or-later** for all code (`LICENSE` = FSF GPLv3 text). Protocol specification documents: CC-BY-4.0. Each source file will carry an SPDX header `SPDX-License-Identifier: GPL-3.0-or-later`.
